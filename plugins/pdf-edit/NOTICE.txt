Плагин «PDF и распознавание» (pdf-edit; распознавание — прежний плагин ocr) — сторонние части

data/tesseract-core-simd-lstm.wasm, data/tesseract-core-simd-lstm.js
  Tesseract OCR, собранный в WebAssembly (пакет tesseract.js-core 6.1.2).
  Tesseract — Apache License 2.0 (https://github.com/tesseract-ocr/tesseract).
  tesseract.js-core — Apache License 2.0 (https://github.com/naptha/tesseract.js-core).
  Leptonica — лицензия BSD-2 (https://github.com/DanBloomberg/leptonica).

data/rus.traineddata.gz, data/eng.traineddata.gz
  Языковые данные tessdata_fast (4.1.0; быстрые модели LSTM, сжаты gzip) — Apache License 2.0
  (https://github.com/tesseract-ocr/tessdata_fast).

data/rus_best.traineddata.gz, data/eng_best.traineddata.gz
  Языковые данные tessdata 4.0.0 (точные модели LSTM в целочисленном виде, сжаты gzip; пакет tesseract.js-data,
  каталог 4.0.0_best_int) — Apache License 2.0 (https://github.com/tesseract-ocr/tessdata,
  https://github.com/naptha/tessdata). Нужны для сложных снимков.

Код самого плагина написан для Пульс Офиса. Распознавание идёт на компьютере человека:
ни картинки, ни текст никуда не отправляются.
